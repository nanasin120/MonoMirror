# IDEA (생각한 아이디어들)

MonoMirror 프로젝트를 진행하며 생각한 아이디어들

## 1. 선생과 학생 방식의 학습
- 영감 : DINO의 학습 방법 유튜브를 보며 저런식이면 갑자기 모델이 터지는걸 막을 수 있지 않을까 생각함
- 구현 : LookAhead를 만듬. 가중치를 0.5만큼씩만 천천히 가져오게 구현

## 2. 여러 방향의 학습
- 영감 : 지금 학습하는게 사실상 이동, 회전, 깊이, 초점 이 4가지임. 이것들을 따로따로 볼 수 있지 않을까?
- 구현 : 아직은 안함. 각자를 중심으로 모델을 돌린 뒤 손실이 가장 낮은걸 채택하는 이런 방식이 좋지 않을까 싶다.
