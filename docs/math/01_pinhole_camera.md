# 01. Pinhole Camera Model (핀홀 카메라 모델)

핀홀 카메라 공식은 3차원의 현실 공간(World Space)과 2차원의 이미지 공간(Image Space)을 연결할 때 사용하는 공식입니다.

## 1. 핀홀 카메라의 기본 구조

<img width="1156" height="935" alt="image" src="https://github.com/user-attachments/assets/cbb615e7-4835-4af1-95b0-235242414167" />

위 그림처럼 핀홀(바늘구멍)을 통해 물체에서 반사된 빛이 들어와 반대편 상에 맺히게 됩니다. 이때 3가지 데이터가 사용됩니다.

1. **물체와의 거리 ($Z$):** 카메라의 바늘구멍(카메라 중심점)에서부터 실제 물체까지의 거리(깊이, Depth)입니다.
2. **초점 거리 ($f$, Focal Length):** 카메라 중심점에서 빛이 닿는 이미지 평면(상)까지의 물리적 거리입니다.
3. **물체의 실제 크기 ($Y$):** 3차원 공간에서 물체가 가지는 물리적 크기(높이)입니다.

최종 목적은 **"3차원 공간의 물체가 카메라 센서(2D 평면)의 어느 좌표($v$)에 찍히는가?"** 를 구하는 것입니다.

---

## 2. 삼각형 닮음비를 이용한 공식 유도

빛이 바늘구멍을 교차하면서 상하가 뒤집힌 삼각형 두 개가 만들어집니다. 이 두 삼각형의 **닮음비**를 이용해투영 공식을 유도할 수 있습니다.

이미지 평면에 맺힌 물체의 2D 높이를 $v$라고 했을 때, 다음과 같은 비례식이 성립합니다.

```math
v : f = Y : Z
```

이 식을 `v`를 기준으로 정리하면

```math
v \cdot Z = f \cdot Y
```

```math
v = \frac{f \cdot Y}{Z}
```

다음과 같이 정리할 수 있습니다. 참고로 수학적으로는 마이너스 부호가 붙어야 하지만 컴퓨터 비전에서는 연산의 편의를 마이너스 부호를 생략합니다.

## 3. 3차원 공간(X, Y, Z)로의 확장
위의 예시는 2차원 단면만을 본것입니다. 이제 가로축(X축)을 추가하면, 3차원 공간의 점 $(X, Y, Z)$가 2D 이미지 평면의 좌표 $(u, v)$로 투영되는 최종 핀홀 카메라 공식이 완성됩니다.
* 가로축 픽셀 좌표 (u):
```math
u = \frac{f \cdot X}{Z}
```
* 세로축 픽셀 좌표 (v):
```math
v = \frac{f \cdot Y}{Z}
```
이 공식을 통해 알 수 있는 것은 "초점 거리$(f)$만큼 키운 뒤, 자신이 가진 깊이 값$(Z)$으로 나누면 2D 픽셀 좌표가 된다"라는 것입니다.

또 알 수 있는것은 깊이 값$(Z)$이 커질수록 좌표는 0에 한없이 가까워 진다는 것입니다.

## 4. 최종 정리
핀홀 카메라 공식을 이용하면 3차원의 좌표를 2차원으로 가져올 수 있고, 2차원의 좌표를 3차원으로 가져갈수 도 있습니다.
